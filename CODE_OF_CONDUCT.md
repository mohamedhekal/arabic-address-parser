# Code of Conduct

We want this project to be welcoming to people of every background, level and dialect.

* Be respectful and assume good intent.
* Give feedback on the work, not the person.
* Explain context when reviewing; do not gatekeep.
* No harassment, discrimination or personal attacks.

Maintainers may edit or remove contributions that break these rules. Report concerns by opening a private security advisory or contacting the repository owner.
